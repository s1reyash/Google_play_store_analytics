# Google Play Store Analytics

A Streamlit dashboard for exploring Google Play Store application and review data. It brings together category, rating, installs, pricing, update, genre, revenue, and user-sentiment views to support lightweight product and market analysis.

## Repository contents

- `appp.py` provides the Streamlit dashboard
- CSV files provide the source app and review data
- `plotes/` contains generated visualisation assets
- Notebooks document the exploratory analysis

## Run locally

Install Python and Streamlit, then run:

```bash
pip install streamlit
streamlit run appp.py
```

Keep the data files and generated visualisation assets in their repository locations when running the dashboard.

## Scope

This is an exploratory analytics project. Its insights depend on the completeness and freshness of the included datasets.
